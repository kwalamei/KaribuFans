# KaribuFans website

Static site generated from templates and data. Working name: KaribuFans.

## Folders
- `data/` – content. `site.json` (name, mode, disclaimer), `modules.json` (the seven pages), `listings/*.json` (vendor listings).
- `templates/` – page layouts (Jinja2).
- `static/` – CSS, JavaScript and images.
- `dist/` – the finished site that Vercel serves. Generated by `build.py`; do not edit by hand.

## Change something
1. Edit a file in `data/` or `templates/`.
2. Run `python3 build.py` (needs Python 3 and `pip install jinja2`).
3. Commit and push; Vercel publishes the new `dist/`.

## Switch the homepage to tournament mode
In `data/site.json` set `"mode": "tournament"` and rebuild. Default is `"everyday"` (Nairobi residents).

## Add a real vendor
In `data/listings/<page>.json` add an entry with `"sample": false`, the WhatsApp number in international format without `+` (e.g. `2547XXXXXXXX`) and, optionally, a phone number. The WhatsApp button then opens a chat with a pre-filled "I found you on KaribuFans" message.

## Deploy on Vercel (first time)
1. Push this folder to a new GitHub repository.
2. In Vercel: Add New → Project → import the repository.
3. Framework preset: Other. Leave the build command empty. Output directory: `dist` (already set in `vercel.json`).
4. Deploy. Vercel gives a free preview address; connect the domain later.
