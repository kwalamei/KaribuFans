# Ticket partners research

Checked: 9 October 2026. Researcher: Claude (desk research only; nobody was contacted).

Method: web search. Direct page fetches of the platforms were blocked from this workspace, so most claims come from search-result snippets of official pages. Labels:
- **[official]** means confirmed on the official page, as shown in the search result for that page
- **[snippet]** means from a search snippet or a news report
- **[unverified]** means the sources conflict or are old

Marx should open every link before acting on it.

Reminder: KaribuFans never sells tickets and never takes payment. Every option below is a link to the seller's own event page.

## 3. Referral links to an event page, and linking restrictions

- **Quicket:** yes, per event. An organiser can give KaribuFans its own promoter or affiliate link to an event page, or a tracked link campaign. Commission is paid only where that organiser has set one. This is the closest fit to "link with a referral code" [official blog plus snippet; 2019 docs, so the current product may differ].
- **HustleSasa:** yes, but only if the event's merchant creates KaribuFans as an affiliate. That means a deal with each organiser, not with the platform [official docs].
- **Mookh:** a referral mechanism was not found. Plain links are clearly welcome, given its brand kit [official].
- **Tikiti, Ticketsasa, Mtickets, FKF:** no referral mechanism found. Plain deep links to event pages are possible (e.g. tikiti.co.ke/e/…, tickets.footballkenya.org/events/…).
- **Restrictions:** no clause banning third-party sites from linking was found in any snippet. **The full terms of use were not read** because page fetches were blocked. Before launch, read each platform's terms for logo use, framing or embedding, and "official partner" wording. Do not use the Mookh "Official Ticketing Partner" seal unless Mookh grants it, since that would imply a status KaribuFans does not have.

## 4. Recommendation

**Approach first:**

1. **FKF Official Ticketing (tickets.footballkenya.org).** It is the official seller for Harambee Stars and some KPL matches, which is KaribuFans' core matchday audience. Even with no commission, a permitted, stable deep link adds credibility. Ask whether a referral code or tracked link is possible and whether club home games will move onto it.
2. **Quicket Kenya.** It is the only platform with a documented referral-link mechanism (promoter networks and affiliate links), it is new in Kenya, and it is looking for distribution partners (it already lists Spotify, Google, Meta and EatOut as channels). Ask for a platform-level partner arrangement, not organiser-by-organiser deals.
3. **HustleSasa.** It is a large Nairobi seller with built-in affiliate tools. Ask whether it will set KaribuFans up as an affiliate across its organisers, or introduce KaribuFans to them.

Next in line: **Mookh** (strong events catalogue, brand kit for linking; a likely candidate in a CAF tender) and **Tikiti** (still used by clubs for derbies).

Do not approach CAF or the AFCON seller yet; wait until CAF names one.
